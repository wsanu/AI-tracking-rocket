# 硬件接线与首次上电检查表

适用组合：HKUST NXT Dual、HK38203 V2.1四合一电调、MicoAir LR24-F-mini V1.0 ELRS接收机、慧眼/Viztra LE071视觉模块。

## 未上电检查

- [ ] 拆除四个螺旋桨。
- [ ] 机架无松动，飞控箭头与机头方向一致。
- [ ] 飞控和电调之间的 `GND`、`VBAT` 极性正确。
- [ ] `PWM1`–`PWM4` 与QGC Actuators中的Motor 1–4一致。
- [ ] `Current`只接电调电流采样输出，比例尚未确认时不用于判断安全余量。
- [ ] 接收机供电电压符合LR24-F-mini规格，共地，TX接飞控RX。
- [ ] 慧眼模块为3.3 V TTL UART，共地，TX接TELEM4/UART8 RX。
- [ ] 没有把5 V、VBAT或RS-232电平接到UART信号脚。
- [ ] USB线和动力电池不会拉扯插头或造成机体移动。

## USB首次上电

- [ ] 不接动力电池，只接USB。
- [ ] QGC识别飞控，`ver all`显示 `HKUST_NXT_DUAL`。
- [ ] 完成传感器和遥控器校准。
- [ ] Channel Monitor中Roll/Pitch/Yaw/Throttle方向正确。
- [ ] 模式开关能选择Stabilized、Altitude和Track。
- [ ] Arm开关独立且方向明确。
- [ ] QGC所有必须配置页面没有红色未完成状态。

## 动力系统拆桨检查

- [ ] 机体固定，周围无人和松散物品。
- [ ] 先开遥控器并确认ELRS连接，再接动力电池。
- [ ] QGC逐个测试Motor 1–4，编号和旋向均正确。
- [ ] 普通模式解锁/上锁可靠，Arm开关可立即停止电机。
- [ ] RC断链会进入预期失控保护。
- [ ] 拨到Track时 `vehicle_status.nav_state=9`。
- [ ] 移动视觉目标时四路 `actuator_motors` 输出产生差动。
- [ ] 拨回人工模式后立即退出Track。

## 上桨前

- [ ] 普通飞行模式的机架、PID、电池和失控保护已在该机体上验证。
- [ ] 桨叶型号、安装方向和紧固方式正确。
- [ ] 有足够空旷场地、保护距离和人工接管方案。
- [ ] 首飞不测试多个新变量；先普通模式低空悬停，再单独测试Track进入/退出。

任何一项不能确认时停止测试。软件设备名不能替代飞控和外设的针脚图。
